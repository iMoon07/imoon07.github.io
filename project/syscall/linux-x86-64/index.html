This table lists Linux x86_64 system calls with their numbers, arguments, and links to documentation.

System calls are invoked via the syscall instruction. The kernel places the return value in %rax. Arguments are passed in registers: %rdi, %rsi, %rdx, %r10, %r8, %r9 (up to 6 args).
